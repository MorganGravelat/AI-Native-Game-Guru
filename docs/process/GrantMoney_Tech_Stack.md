## When Adding a New Tool

Record:

1. What problem does it solve?
2. Why was it selected?
3. What does it generate?
4. What license or usage restrictions apply?
5. What information is uploaded to it?
6. How will a human verify the result?
7. What is the fallback if the output is unusable?
